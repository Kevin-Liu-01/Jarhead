# site/docs

The briefs the landing page was designed and built from, kept here because they were written in a scratch folder that
the system cleans out. Read the current two before changing the page.

## Current

- `SCRATCH.md` · the brief (2026-10-01): everything Kevin has said about the page, what it must have, what was thrown away,
  the canon and the judging bar.
- `DESIGN.md` · the page as built: the composition, the sticky top, the sections and their ids, the drawings, type, space,
  colour, motion, both themes, and how to add a section.
- `ART-STYLE.md` · the law for the drawings in `components/art/` (the 2.5D stack, filled, the blob in it).
- `COPY.md` · the copy deck: the only source of strings on the page (plus the app's own rendered text for the island and
  the Console window's rows). Short declarative sentences, one idea each, no metaphors, no em dashes.

## History (what was tried; never copy a layout from these)

- `IMMERSE.md` · the earlier design: the page as the Console window and rails, at the app's density.
- `ITERATE.md` · the seven asks that shaped the earlier build (the glass install, GitHub stars, the one-line headline).
- `CENTER.md`, `ART.md` · the earlier centre column and the first brief for the pictures.
- `SPACE.md` · the Console kit port (`components/kit`) and the spacing scale of that pass.
- `MAILROOM.md` · the reference study of mailroom.kevinliu.studio; its frame was tried and removed.

Icons: every brand mark comes from `@thesvg/react` (`mono` variant, per-icon import, inherits the text colour); generic
glyphs are the kit's own filled SVGs in `components/kit/Glyph.tsx`; never SF Symbols, never Heroicons, never emoji. Agent
marks are the app's (`components/kit/AgentMark.tsx`).
