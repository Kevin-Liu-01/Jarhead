# site/docs

The briefs the landing page was designed and built from, kept here because they were written in a scratch
folder that the system cleans out. Read them before changing the page.

- `COPY.md` · the copy deck: the only source of strings on the page (plus the app's own rendered text for the
  island bands and the rail rows). Short declarative sentences, one idea each, no metaphors, no em dashes.
- `IMMERSE.md` · the design: the page is Jarhead's own surfaces (the Console window and rails, the notch island,
  the blob) on dithered grounds with the kit's glyphs, at the app's density. What "generic" means and is banned.
- `ITERATE.md` · the seven asks that shaped the current build (the glass install button, GitHub stars, the
  one-line headline, the blob on the notch island, the states, side-by-side sections, the real rail).
- `SPACE.md` · the earlier pass: the Console kit port (`components/kit`), the spacing scale, install as a pane.
- `MAILROOM.md` · the reference study of mailroom.kevinliu.studio; its frame was tried and removed, its copy
  discipline stayed.

Icons: every brand mark comes from `@thesvg/react` (`mono` variant, per-icon import, inherits the text colour);
generic glyphs are the kit's own filled SVGs in `components/kit/Glyph.tsx`; never SF Symbols, never Heroicons,
never emoji. Agent marks are the app's (`components/kit/AgentMark.tsx`).
